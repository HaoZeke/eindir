* Overview

eindir has the pieces that optimisers and samplers on a box in R^D share: an objective trait with box bounds, Halton point sets, gradient adapters, a coloured-noise thermostat for the generalized Langevin equation (GLE), and surrogate models.
It is a Rust crate, =eindir-core=, with a Python package, =eindir=, and a C library with a C++ companion header.
The [[https://github.com/HaoZeke/anneal][anneal]] optimiser is built on it.

- Objectives: =Objective<T>= over =Bounds<T>=, with batch and parallel evaluation, and =TryObjective= for objectives that can fail.
- Point sets: Halton designs scaled to a box, with seeded shifts and corner-anchored variants.
- Gradients: the =Gradient<T>= trait, analytic and central-difference adapters, and forward-mode automatic differentiation with the =autodiff= feature.
- GLE thermostat: =GleThermostat= with a fitted drift that samples a band of frequencies evenly.
- Surrogates: an additive Chebyshev model with independence sampling, a total-degree Chebyshev polynomial, and objectives restricted to a subspace.
- Test functions: =Rastrigin=, =Rosenbrock=, =Ackley= and =StybTang2D=.

Python covers objectives, bounds and point sets; the rest is Rust-only.
The C ABI passes objectives between C and Rust, with a version stamp and a semantic descriptor to check that both sides agree.
