* Python (maturin)

The wheel on PyPI is built by maturin with the =python= feature.
It is abi3, so one wheel serves Python 3.10 and newer.
The extension is the submodule =eindir._core=; the rest of =python/eindir/= is pure Python.
For development, =maturin develop --features python= installs both into the active virtual environment.
[[file:reference/api-primitives.org][Python API]] lists what is there.

* C and C++ (cargo-c)

cargo-c builds the shared and static libraries with the =capi= feature, generates =eindir-core.h= with cbindgen, and writes =eindir-core.pc=:

#+BEGIN_SRC bash
cargo cinstall --release --prefix="$PREFIX" --libdir=lib
pkg-config --cflags --libs eindir-core
#+END_SRC

The header is plain C99, compiles as C++, and includes =dlpack/dlpack.h=, which must come from DLPack 1.0 or newer.
Tensor arguments are =struct DLManagedTensorVersioned=.
=include/eindir-core.hpp= includes the C header and adds =eindir::version()= in =namespace eindir=.
[[file:reference/c-api.org][C API]] lists the functions.

* Build-system glue

With =eindir-core.pc= on =PKG_CONFIG_PATH=:

** Meson

#+BEGIN_SRC meson
eindir_core_dep = dependency('eindir-core')
executable('myprog', 'main.cpp', dependencies: eindir_core_dep)
#+END_SRC

** CMake

#+BEGIN_SRC cmake
find_package(PkgConfig REQUIRED)
pkg_check_modules(EINDIR_CORE REQUIRED IMPORTED_TARGET eindir-core)
target_link_libraries(myprog PRIVATE PkgConfig::EINDIR_CORE)
#+END_SRC

Add the DLPack include directory yourself when it is not in a default path.
