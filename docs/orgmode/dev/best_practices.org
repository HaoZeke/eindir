#+TITLE: Best Practices
#+OPTIONS: toc:nil todo:nil num:nil author:nil ^:nil

* Define the objective once

Write the function once, as an =Objective= in Rust, a =PyObjective= in Python or an =eindir_objective_t= in C, and pass the same object to every driver.
Comparisons between drivers then differ only in the driver.

* Use low-discrepancy starts

When the bounds are known, =low_discrepancy_points= with a fixed =skip= gives starts that cover the box and are the same on every run.
Use =shifted_low_discrepancy_points= with different seeds for independent replicas.

* Reuse the GLE drift

The drift matrix sets the speed of the thermostat and the covariance sets its temperature, so one drift serves every temperature.
Build it once with =optimal_sampling_drift= and rebuild the =GleThermostat= only when =dt= changes.

* Accept surrogate proposals with the true objective

A surrogate is cheap but approximate.
Use its proposals and values to decide where to look, and decide what to keep, and what to report, with the true objective.
Count the pilot evaluations that fitted the surrogate in the evaluation budget.

* Keep arrays where they live

With device arrays, =eindir.to_reference= and =eindir.require_same_placement= keep every array in the namespace and on the device of a reference array, and =dlpack_device= reads where an array lives without converting it.
=eindir._core= itself takes only NumPy float64 arrays on the CPU.
