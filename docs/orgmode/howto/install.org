* Python
#+BEGIN_SRC bash
pip install eindir
#+END_SRC

The extras are =plotter= (matplotlib and cmcrameri) and =testing= (array-api-strict, pytest and pytest-cov), as in =pip install "eindir[plotter]"=.

* Pixi (full stack, recommended for development + docs)
#+BEGIN_SRC bash
pixi install
#+END_SRC

* From source (Rust + Python)
#+BEGIN_SRC bash
cargo build --release
cargo cinstall --release --prefix /usr/local   # for C/C++ consumers
# Python: maturin develop --features python (or pixi run -e python python-build)
#+END_SRC
