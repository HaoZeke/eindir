==========
Quickstart
==========

This page evaluates a function at eight well-spread points in a box, first from Python and then from Rust.
Both draw the same Halton points and find the same best start.

* Install

Python:

#+BEGIN_SRC bash
pip install eindir
#+END_SRC

Rust, in =Cargo.toml=:

#+BEGIN_SRC toml
[dependencies]
eindir-core = "0.6"
ndarray = "0.17"
#+END_SRC

The newest release on crates.io is 0.6.0 and on PyPI 0.5.1.
For the main branch, use =eindir-core = { git = "https://github.com/HaoZeke/eindir" }= or run =maturin develop --features python= in a checkout.
[[file:howto/install.org][Installation]] has the other routes.

* Python

=_core.Bounds= is a box and =_core.PyObjective= wraps a Python function as an objective over it.
=eindir.low_discrepancy_points= returns Halton points in the box as an =(n, d)= array.

#+BEGIN_SRC python
import numpy as np
import eindir
from eindir import _core

low = np.array([-5.12, -5.12])
high = np.array([5.12, 5.12])
obj = _core.PyObjective(lambda x: float(np.sum((x - 1.0) ** 2)), _core.Bounds(low, high))

starts = eindir.low_discrepancy_points(low, high, 8)
values = [obj.eval(row) for row in starts]
best = int(np.argmin(values))
print(starts[best], values[best])
#+END_SRC

#+BEGIN_EXAMPLE
[1.28       2.84444444] 3.480375308641971
#+END_EXAMPLE

=_core= takes contiguous float64 NumPy arrays only; =eindir.low_discrepancy_points= converts lists for you.

* Rust

An objective is a type that implements =Objective<f64>=: its dimension, its bounds and its value.
=eval_batch= evaluates the rows of a 2-D array.

#+INCLUDE: "../../examples/quickstart.rs" src rust

#+BEGIN_EXAMPLE
[1.2800000000000002, 2.844444444444443] 3.480375308641971
#+END_EXAMPLE

The file is =examples/quickstart.rs=, and =cargo run --example quickstart= runs it.
