#+TITLE: Surrogates
#+OPTIONS: toc:nil todo:nil num:nil author:nil ^:nil

A surrogate is a cheap model of the objective, fitted on a pilot design.
eindir has three: an additive model in all coordinates, a polynomial on a few directions, and a wrapper that restricts an objective to those directions.
All three implement =Objective=, so a driver can use them wherever it takes an objective, and a sampler can use them for proposals while it still accepts or rejects with the true objective.

* The additive surrogate

=AdditiveSurrogate= models =f(x) ≈ c + sum_j g_j(x_j)=, with each =g_j= a Chebyshev series in one coordinate.
This is a generalized additive model [1], and Chebyshev series are a natural basis for smooth functions on an interval [2].
In the language of tensor trains it is a rank-1 functional tensor train over all =d= coordinates.

=fit= sets =c= to the pilot mean and refits one coordinate at a time against the residual of the others (backfitting, [1]), 12 passes by default.
Each coordinate's columns are centred on their pilot means, because under uniform sampling the even Chebyshev polynomials have nonzero mean and an uncentred fit would leak into =c=.
A pass costs one small solve per coordinate with a cached factor, so the fit is linear in =d=.

* Independence proposals

The tempered density =exp(-f(x) / T)= of an additive model factorises into one density per coordinate.
=sample= draws each coordinate by inverse CDF on a grid, which costs =O(d m)= for a grid of =m= nodes, and one draw puts every coordinate near its own tempered optimum at once.
When =f= is separable this is an exact draw from the surrogate's tempered law; when it is not, the proposal is biased toward the additive part, and a Metropolis-Hastings accept step on the true objective removes the bias.
The additive independence driver of anneal works this way.

* Reduced objectives and active subspaces

Many functions of many variables vary mostly along a few directions.
Active subspace methods find them from the eigenvectors of the average outer product of the gradient [3].
=ReducedObjective::new(inner, origin, basis, bounds)= evaluates =inner= at =origin + basis r=, so a driver can search the low-dimensional =r= instead of =x=.
The point is clipped to the bounds of =inner= before evaluation, and the gradient is =basis^T ∇f= with the clipped components of =∇f= set to zero.
eindir does not compute the basis; the caller supplies it.
=ChebyshevSurrogate= is a total-degree Chebyshev polynomial with value and gradient, for a cheap model on the reduced box; the caller supplies its terms and coefficients.
