#+TITLE: Tutorials

The tutorials build up from the [[file:quickstart.org][Quickstart]].
Each one runs as written: CI runs the Python blocks of the manual, and the Rust code is included from =examples/=, which =cargo test= builds.

| Tutorial                                                 | Language       | What it covers                                                   |
|----------------------------------------------------------+----------------+------------------------------------------------------------------|
| [[file:tutorials/quickstart.org][Quickstart with Python]]       | Python         | An objective with a gradient, start points, the pure-Python classes |
| [[file:tutorials/low-discrepancy.org][Low-discrepancy points]]  | Python, Rust   | Halton designs, shifted replicas, corner-anchored designs        |
| [[file:tutorials/gle-thermostat.org][GLE thermostat]]          | Rust           | The coloured-noise thermostat on its own                         |
| [[file:tutorials/surrogates.org][Surrogates]]                  | Rust           | An additive surrogate, its proposals, a reduced objective        |

The GLE thermostat and the surrogates have no Python binding.

To check the version of an installed package:

#+BEGIN_SRC python
import eindir
print(eindir._core.__version__)
#+END_SRC

=eindir.__version__= does not exist.
