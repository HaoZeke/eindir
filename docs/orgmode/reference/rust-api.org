The pages under this one are generated from the doc comments of the =eindir-core= crate by =sphinxcontrib_rust= and =sphinx-rustdoc-postprocess=.
=cargo doc --all-features --open= builds the same documentation with rustdoc, including the =autodiff= and =capi= items, and [[https://docs.rs/eindir-core][docs.rs]] has it for each release.

Public items document their units, defaults, errors and panics where they have any, and many carry an example that =cargo test= runs.
