This tutorial wraps a Python function and its gradient as an objective, draws start points inside its bounds, and evaluates them.
It needs =pip install eindir= and NumPy.

* Step 1: an objective with a gradient

=_core.Bounds(low, high, slack=1e-6)= is the box.
=_core.PyObjective(fn, bounds, grad_fn=None)= wraps =fn=, which takes a 1-D float64 array and returns a float.
=grad_fn=, when given, returns the gradient as an array of the same length.

#+BEGIN_SRC python
import numpy as np
from eindir import _core

low = np.full(2, -5.12)
high = np.full(2, 5.12)


def rastrigin(x):
    return float(10.0 * len(x) + np.sum(x**2 - 10.0 * np.cos(2.0 * np.pi * x)))


def rastrigin_grad(x):
    return 2.0 * x + 20.0 * np.pi * np.sin(2.0 * np.pi * x)


obj = _core.PyObjective(rastrigin, _core.Bounds(low, high), grad_fn=rastrigin_grad)
print(obj.dim, obj.eval(np.zeros(2)), obj.grad(np.array([0.5, 0.0])))
#+END_SRC

Without =grad_fn=, =obj.grad= raises =ValueError=.
Python has no finite-difference fallback, so pass a gradient or difference the function yourself.

* Step 2: start points

=eindir.low_discrepancy_points(low, high, n, skip=1)= returns =n= Halton points in the box.
The same arguments always give the same points, so a run can be repeated exactly.

#+BEGIN_SRC python
import numpy as np
import eindir
from eindir import _core

low = np.full(2, -5.12)
high = np.full(2, 5.12)
obj = _core.PyObjective(
    lambda x: float(20.0 + np.sum(x**2 - 10.0 * np.cos(2.0 * np.pi * x))),
    _core.Bounds(low, high),
)

starts = eindir.low_discrepancy_points(low, high, 8)
values = np.array([obj.eval(row) for row in starts])
print(starts.shape, values.min())
assert np.all((starts >= low) & (starts <= high))
#+END_SRC

* Step 3: the pure-Python classes

=eindir.NumLimit= and =eindir.ObjectiveFunction= are plain Python and separate from =_core=.
A subclass of =ObjectiveFunction= implements =singlepoint=, =multipoint= and =__repr__=; calling it counts calls in =.calls=.

#+BEGIN_SRC python
import numpy as np
import eindir


class Sphere(eindir.ObjectiveFunction):
    def singlepoint(self, pos):
        return float(np.sum(pos**2))

    def multipoint(self, pos):
        return np.sum(pos**2, axis=-1)

    def __repr__(self):
        return "Sphere"


limits = eindir.NumLimit(low=np.full(2, -1.0), high=np.full(2, 1.0), dims=2)
f = Sphere(limits)
print(f(np.array([0.5, 0.5])), f(np.array([[1.0, 0.0], [0.0, 0.0]])), f.calls)
#+END_SRC

Pass =dims= to =NumLimit=: it defaults to 1, and =ObjectiveFunction= uses it to tell one point from many.
