GLE thermostat

This tutorial builds the coloured-noise thermostat of the generalized Langevin equation (GLE), starts it at equilibrium and checks that the momenta keep their thermal variance.
The thermostat is Rust-only; Python has no binding for it.
[[file:../explanation/gle.org][The GLE thermostat]] explains what it computes and why.

* What each call does

- =optimal_sampling_drift(omega0)= returns the drift matrix =A=, square of size =OPTIMAL_SAMPLING_NS + 1= (13).
  It is a fitted reference scaled by =omega0=, so the band it damps evenly is =[omega0, 100 omega0]=.
  Pick =omega0= near the slowest frequency you want to sample, in inverse units of =dt=.
- =GleThermostat::canonical(&drift, dt, temperature, kb)= precomputes the propagator =T = exp(-dt A)= and the noise factor =S= for one step.
  The fourth argument is Boltzmann's constant, not a mass; there is no mass argument because the state holds mass-scaled momenta.
- =sample_stationary(&c, dim, kb, &mut rng)= draws a state of shape =(ns + 1, dim)= from the stationary law =N(0, kb c)=.
  Pass the covariance the thermostat was built with, =temperature * I= for =canonical=.
- =step(&mut state.view_mut(), &mut rng)= applies =s <- T s + S xi= in place.
  Row 0 is the physical momentum of each coordinate and rows 1 to =ns= are the auxiliary momenta.

* In an integrator

The thermostat only updates momenta, and each call to =step= advances them by the =dt= it was built with.
Call it once per timestep between the force kicks of your integrator, or build it with =dt / 2= and call it before and after the kicks for a symmetric splitting.
The anneal GLE driver does this; [[file:../howto/using-with-anneal.org][Using with anneal]] says where it plugs in.
